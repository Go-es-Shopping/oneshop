店鋪設置與整合

管理自訂網域、金流與物流 API，以及店鋪成員權限。

網域管理

綁定自訂網域，讓顧客透過您的專屬網址進入賣場。

請在您的 DNS 設定中新增 CNAME 紀錄，將上述網域指向 go-shop.com。

金物流開通嚮導

依步驟完成 LINE Pay、信用卡與超商取貨的 API 接通。

1 LINE Pay
2 信用卡
3 超商取貨

STEP 1：LINE Pay 串接

請至 LINE Pay 商家後台取得 Channel ID 與 Channel Secret Key，並填寫於下方。

STEP 2：信用卡金流串接

選擇您的信用卡收單銀行並填寫 API 金鑰（支援綠界、藍新等）。

STEP 3：超商取貨物流

設定 7-11、全家、萊爾富等超商取貨的物流 API。

多權限管理

區分「店長」與「小幫手」的查看與編輯權限，保障店鋪安全。

👑

店長

擁有完整權限，可管理店鋪設定與成員

✓ 查看所有訂單與報表 ✓ 編輯商品與庫存 ✓ 店鋪設置與網域 ✓ 金物流與權限管理

小幫手

點選權限標籤可自由勾選或取消，未勾選的項目小幫手將無法使用

以下權限僅店長可擁有，無法開放給小幫手：店鋪設置與網域、金物流與權限管理
