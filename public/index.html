店鋪設置與整合

管理自訂網域、金流與物流 API，以及店鋪成員權限。

店家網址設定

設定店家 ID，顧客可透過 www.goezshopping.com 加上店家 ID 進入賣場。

提示：店家 ID 只能輸入小寫英文與數字（3~30 字元）。

預覽網址：www.goezshopping.com/請輸入店家ID

金物流開通嚮導

依步驟完成 LINE Pay、信用卡與超商取貨的 API 接通。

1 LINE Pay
2 信用卡
3 超商取貨

STEP 1：LINE Pay 串接

請至 LINE Pay 商家後台取得 Channel ID 與 Channel Secret Key，並填寫於下方。

STEP 2：信用卡金流串接

選擇您的信用卡收單銀行並填寫 API 金鑰（目前支援藍新 NewebPay）。

藍新 NewebPay 設定

提示：此頁為示範介面，正式串接時請由後端安全儲存金流金鑰。

STEP 3：超商取貨物流

設定 7-11、全家、萊爾富等超商取貨的物流 API。
